# Phoenix AI portable preview for Windows x64

Keep **Phoenix AI.exe**, **App**, and **Models** together in a writable folder.

1. Open **Get-Model.cmd** in **Models** and select **LFM2.5 230M chat**. Confirm the listed downloads.
2. For voice, repeat with **Parakeet dictation** and **Kokoro speech output**.
3. Open **Phoenix AI.exe**.

The model helper verifies file sizes and SHA-256 hashes before installing. Confirmations show the publisher and size for each file. Optional chat models and the decision router are available in the same menu.

First-generation AMD XDNA chat and dictation require a compatible Ryzen AI Phoenix or Hawk Point system and the AMD NPU driver. Chat can also run on the CPU or a compatible Vulkan GPU.
